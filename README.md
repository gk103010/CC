# Chosen Creators (CC)

Chosen Creators digital agency website.

## Project Structure

- **`V1/`**: Version 1 source code and assets (Next.js 14, React 18, Three.js / React Three Fiber, Framer Motion, Tailwind CSS).

## Getting Started

To run the project locally:

```bash
cd V1
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
